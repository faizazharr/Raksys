# Screenshots

Drop the PNG files below into this folder. The main [`README.md`](../../README.md) already references them by these exact names, so nothing else needs editing once they exist.

**Capture tips**

- Use the built-in dark theme, window size around **1440 × 900**, PNG format.
- Use demo/dummy data only — no real hostnames, credentials, or production tables.
- Prefer one clear feature per shot; keep each file under ~1 MB (e.g. run through `pngquant`).
